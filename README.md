# on the subject of attribution

## 2026: the year of hysteria

hi there, i'm jane michelle. 2026 has been a weird year in which people are
talking about the purity of the profession, and somehow someone who produces a
bunch of code, regardless of quality, is somehow not a software engineer.
since about june of this year, i've produced about a million lines of code.
thats approximately, what, 40,000 lines a week, give or take some rounding?

i'm kind of tired of the purity tests, so i'm going to just say some things.

- i in fact use all this code basically every day
- code quality is a separate issue of provenance
- i'm not trying to represent my software as hand-written by some dude with a
  moustache drinking an ipa in west oakland in a converted warehouse.
- a large part of the software i write is actually code quality tools, which i
  wish i'd had as an engineer back when it was only humans writing software.
  and emacs. emacs wrote a lot of software back then.

i have been using software you might call "ai" for at least a few years. the
only thing that was controversial about this when i started was that i cared
about this at all, and i went to pains to explain which software had been
authored with the help of ai. people thought i was crazy for saying that, and i
did it anyway, and i moved on with my life.

## also 2026: stuff i use for coauthoring with ai

- [game](https://github.com/janearc/game): a build tool with substantially
  enhanced linting for use with agent pairing
- [libninja](https://github.com/janearc/libninja): a code linting tool for
  golang that enforces basic code decency
- [okapi](https://github.com/janearc/okapi): a documentation and comments
  linter
- [libreadme](https://github.com/janearc/libreadme: a linter enforcing styles
  that are legible to low-vision users
- [pzm](https://github.com/janearc/puzzlemouth): a set of included
  functionality so agents build software with a reasonable set of features, from
  the first branch.
- my "[bookshelf](https://github.com/janearc/bookshelf)": the docs i give
  agents for guidance on how to write software.
